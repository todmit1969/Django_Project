# Проект по работе с Django

## Описание:
Созданы два шаблона home.html и contacts.html.
Создаты контролеры для отображения этих шаблонов
и настроена маршрутизация. Для стилизации использован Bootstrap.
## Для установки клонируйте репозиторий 

git clone https://github.com/todmit1969/Django_Project

## Использование 

Запустите сервер python manage.py runserver и
перейдите по ссылке.
